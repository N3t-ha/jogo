📋 Game Design Document (GDD) & Personalização

Este jogo foi desenvolvido com arquitetura modular de alta performance. Caso você queira adaptar o jogo para as especificações exatas do seu GDD, todos os sistemas são configuráveis:

🎮 Estrutura de Mecânicas Atuais

  • Gênero: Arcade Space Shooter 2D com física suave e partículas.
  • Sistemas de Entidades: Jogador, Tiros, Inimigos (Scout, Heavy, Boss) e Power-ups (Escudo, Laser Triplo, Boost).
  • Áudio Dinâmico: Sintetizado via Web Audio API (não necessita carregar arquivos MP3/WAV externos).
  • Salva de Progresso: Recordes mantidos via LocalStorage.

⚙️ Como aplicar seu GDD personalizado:

Você pode alterar os parâmetros de velocidade, vida, cores e comportamento direto nos arquivos JavaScript dentro de src/js/entities.js e src/js/game.js.

🔄 Como Funciona o Sistema de Rollback & Git

Seu projeto conta com histórico de versões comitadas via Git na pasta C:\Users\Aluno\Documents\GitHub\jogo. Caso você altere o código e queira **voltar a uma versão funcional**, siga as instruções:

1. Ver histórico de edições comitadas:

git log --oneline

2. Cancelar alterações locais não salvas:

git reset --hard HEAD

3. Restaurar uma versão marcada por tag (ex: v1.0.0):

git checkout v1.0.0

4. Enviar o jogo pronto para o seu repositório no GitHub:

git add .
git commit -m "feat: versão final do jogo"
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSISTORIO.git
git branch -M main
git push -u origin main
